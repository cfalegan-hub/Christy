# Reports

Monthly check-in reports land here, one file per month:
`YYYY-MM-summary.md`.

Each report covers, using whatever data exists in `finance/` at the time:

- Cash flow summary (income vs. expenses for the month)
- Invoice status (outstanding, overdue, paid)
- Budget vs. actual, by category
- Any items from `docs/alerts.md` that triggered
- Anything moved to/from `docs/open-questions.md`

**Assumption:** monthly cadence, generated on the 1st of each month for the
prior month. Say the word if you'd prefer weekly, quarterly, or on-demand
only.

only 1–3 Jul since the statement on file cuts off there — a fuller report
will follow once the rest of July's statement is loaded.
